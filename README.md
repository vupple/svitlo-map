# Світлокарта

Мапа відключень світла, де будинки зі [Світлоботом](https://svitlobot.in.ua) зафарбовані за статусом: зелені — світло є, червоні — світла немає, решта будинків сірі.

**Відкрити мапу:** https://vupple.github.io/svitlo-map/

## Звідки дані

- Статуси світла — [Світлобот](https://svitlobot.in.ua), сервіс, що стежить за електрикою в будинках і сповіщає про відключення в Telegram. Мапа читає їхній публічний API напряму з браузера й оновлюється щохвилини.
- Підкладка мапи — [OpenFreeMap](https://openfreemap.org), дані © [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Контури будинків і районів — OpenStreetMap через [Overpass API](https://overpass-api.de), зібрані заздалегідь у `buildings.js`.

## Як це влаштовано

- `index.html` — уся мапа: MapLibre GL, бокова панель зі статистикою по містах і районах.
- `build_buildings.py` — знаходить будинок для кожного бота та межі районів міст і записує їх у `buildings.js`. Потрібен лише Python 3, без залежностей.
- `.github/workflows/update-buildings.yml` — щонеділі перезбирає `buildings.js`, щоб на мапу потрапили нові боти. Можна запустити вручну у вкладці Actions.

Бот, для якого будинок ще не зібрано, все одно з'явиться на мапі на близькому зумі: сторінка шукає будинок у векторних тайлах.

## Запуск локально

```bash
python3 -m http.server 8765
```

Потім відкрийте http://localhost:8765.
